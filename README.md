# 🩺 Human Disease Predictor

## 📖 About the Project
The Human Disease Predictor is a fast, machine learning-based web application that analyzes user-selected medical symptoms to predict the most likely diseases. 
It provides the top 3 potential diagnoses along with their probability percentages, serving as a quick and reliable preliminary screening tool.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Machine Learning Model:** Scikit-Learn (Multinomial Naive Bayes)
* **User Interface:** Gradio
* **Data Processing & Storage:** Pandas, Joblib
* **Deployment / Hosting:** Render, GitHub

**Live Application:** https://disease-predictor-cj6i.onrender.com/
